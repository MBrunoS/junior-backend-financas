---
title: "Materiais do Projeto"
description: "Baixe o starter back-end e valide sua API com o contrato e os clientes oficiais."
---

Os materiais vivem neste repositório público. Comece em `student-starter/`, consulte os enunciados em `sprints/` e use `kit/` para validar a integração.

As tags `sprint-N-materials` congelam o pacote de cada etapa, mas a implementação NestJS deve ser construída por você. A solução completa será publicada com as aulas da trilha; a API executável em `kit/reference-api/` já define o comportamento esperado.

Com sua API na porta 3000:

```bash
cd kit
API_BASE_URL=http://localhost:3000 pnpm contract:test
```

Depois, execute o cliente oficial:

```bash
cd kit/reference-web
pnpm install
VITE_API_URL=http://localhost:3000 pnpm dev
```
